# Storybook - Simple 2D Game

## Overview
A simple 2D platformer game created with Unity 6000.3.0b4.

## Features
- Player movement with arrow keys or WASD
- Jump mechanic with Space bar
- Basic physics-based gameplay

## Setup
1. Open the project in Unity
2. Create a 2D scene with:
   - Player GameObject (add Rigidbody2D, BoxCollider2D, and PlayerController script)
   - Ground GameObject (add BoxCollider2D, set Tag to "Ground")
   - Main Camera (set to Orthographic)

## Controls
- Arrow Keys / WASD: Move left and right
- Space: Jump

## Development
This is a basic template. Extend it by adding:
- More levels and obstacles
- Enemies and collectibles
- Score system
- Sound effects and music
